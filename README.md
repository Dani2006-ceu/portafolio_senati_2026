# Portafolio — Daniel Adin Izquierdo Segura

Estudiante de Ingeniería de Software con Inteligencia Artificial en Senati (Ucayali, Perú).

## Qué incluye
- `index.html`: portafolio con fotocheck colgante (se arrastra y rebota) y editor con la estrella ⭐.
- `tarjeta.html`: tarjeta de contacto que abre el QR del fotocheck (WhatsApp, correo, guardar contacto).
- `vercel.json`: configuración para publicar en Vercel.

## Publicar
- **Vercel:** importa este repositorio y publica, sin configuración extra.
- **GitHub Pages:** Settings → Pages → Branch `main` → carpeta `/ (root)`.

## Editar
Toca la estrella, edita, presiona **Descargar index.html** y reemplaza el archivo en este repositorio.
